# App icon provenance

The SsbmPad app icon is an original AI-generated cartoon sun created for this
project on 2026-08-08 with OpenAI's built-in image generation tool. It was
prompted as a generic, friendly sun on an opaque turquoise sky background,
with no text, controller, game imagery, brand marks, or copyrighted
characters. The selected source was resized to the 1024×1024 iOS/iPadOS app
icon master stored in this asset catalog.
