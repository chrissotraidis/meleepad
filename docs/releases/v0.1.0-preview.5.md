# MeleePad v0.1.0 Preview 5 — Slippi support

Build 26 adds MeleePad-supported Slippi integration on iOS/iPadOS: account login,
matchmaking, rollback, replay recording and persistent connection diagnostics.
The maintainer completed two real Unranked games on a physical iPad. This is
hardware evidence, distinct from Simulator and local transport tests.

Ranked follows Slippi's subscription/free-day policy. Direct, Teams and Party
are enabled but have not received equivalent full-match hardware acceptance.
Network quality, slowdowns and earlier disconnects remain under investigation;
this release does not claim their root cause is fixed. macOS Slippi acceptance
is also incomplete. This is an independent port, not a Project Slippi endorsement.

## Slippi account setup

See the [README profile-import guide](../../README.md#import-your-slippi-profile-on-iphone-or-ipad). Download your own Slippi `user.json`, save it in Files,
then choose **Slippi Multiplayer → SET UP SLIPPI → Import Account** in MeleePad.
The profile import does not supply game data or a native module.

## Installation and upgrades

The public IPA is an **unsigned, module-free app shell**, not playable as
downloaded. Importing an ISO alone does not supply the native Slippi module.
Generate compatible modules from your own USA v1.02 game image, stage your own
game data and sign locally as described in [Slippi builds](../SLIPPI-BUILD.md).
No game, account, replay, save or signing profile is distributed.

For existing private builds, preserve the bundle identifier and signing team
and install in place. Back up your app documents/settings first; do not delete
the app to update. Public shell installation does not automatically preserve
private modules that were embedded in an older app bundle.

## Source and validation

The C++ adapter and native libraries are built from pinned maintained sources,
including the Slippi Rust FFI. Bootstrap performs submodule checkout and source
verification without replaying patches. The release includes an IPA checksum;
matching app and dependency revisions and build provenance accompany the asset.
