# MeleePad 0.2.5

Fixes iPhone and iPad imports that could report success after a game resource was
only partially written, for example when storage ran out. Import now checks each
extracted file against the disc's expected length before activating the new data.
An incomplete extraction shows an error and leaves the previous installation and
saves in place so you can free space and try again.

Use PadMint to build the updated app from your own supported Melee disc. Install
over your existing copy with the same signing identity to preserve its data.
This release contains the unsigned app shell without game code, the PadMint
recipe, and checksums. PadMint builds your game module locally; keep the resulting
personal IPA private.

The regression runs the app's actual extraction wrapper with a synthetic DiscIO
boundary. It covers complete output, a truncated final file with the same file
count, missing files, a directory in place of a file, and nested/empty files under
AddressSanitizer and UndefinedBehaviorSanitizer. The unmodified wrapper fails the
truncated-file case. This establishes the extraction repair, not physical-device
or provider-specific picker acceptance, gameplay, audio, or performance.
