# MeleePad v0.1.0 Preview 7 — clearer in-game controls

Preview 7 packages build 29. The in-game three-dot menu now has a short main
list with Slippi, display, controls, game data, help, and Exit to Home. The
existing actions remain available under those groups. Peer warnings are
shorter and sit below the menu button instead of across Slippi's top-left
performance warning and the match timer. Steady Wi-Fi matches no longer keep
a status banner on screen.

**Slippi Connection Check** is under **Home Settings → Slippi & Online** and
**••• → Slippi & Online** during a game. It reports the network path and the
median response from three requests to Slippi's website. It does not measure
matchmaking UDP or predict an opponent's ping. During a match, the compact
indicator warns about high peer ping, rollback stalls, or missing ping samples.
Rollback stalls can also reflect a slow device.

The maintainer installed build 29 in place on a physical iPad and confirmed
that Melee v1.02, the Slippi module, the account, and settings remained ready.
A build 28 Unranked match connected and played but suffered high peer ping
and poor frame pacing. **Preview 7 does not claim a lag fix.** The revised menu
and warning still need a live-opponent visual retest.

## Download and build boundary

`MeleePad-v0.1.0-preview.7-module-free-unsigned.ipa` is an unsigned ARM64 app
shell for inspection. It contains no game image, generated game or Slippi
module, account, saves, or signing material. It is **not playable as
downloaded**. Importing an ISO or `user.json` cannot add the missing modules.
Follow the [build guide](../SLIPPI-BUILD.md) to make and sign a complete
private build from your own supported game image. Do not install the public
shell over an existing private playable build; it would replace the bundled
modules.
