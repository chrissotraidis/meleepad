# Tests

SsbmPad treats runtime evidence as authoritative: compilation success is not
gameplay success. These focused source regressions protect the shell behavior
ported from the pinned SunPad reference. Run all of them through:

```sh
scripts/check-repository.sh
```

They do not replace the hands-on Simulator, macOS, physical-device, or netplay
acceptance rows in `docs/PRD.md`.
