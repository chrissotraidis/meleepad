# MeleePad 0.2.4

Fixes Mac builds from a Melee USA v1.02 disc that stopped after compilation with
`modules-macos14/GALE01/active-module.txt: No such file or directory` (#49).
The packager now uses the module prepared from your disc without requiring a
previous v1.00 build. Each revision keeps its own module directory, and the
legacy v1.00 fallback never contains v1.02 code.

In PadMint, choose **MeleePad**, your own supported disc, and **This Mac** again.
PadMint fetches the latest MeleePad release; this fix does not require a new
PadMint version. The iPhone/iPad app is rebuilt with the new version number;
its behavior is unchanged.

The release contains the unsigned iPhone/iPad app without game code, the PadMint
recipe, and checksums. PadMint builds the game module locally from your disc.
The resulting personal IPA or Mac app must not be shared.

This packaging repair does not establish new gameplay, audio, or performance
acceptance. Install over an existing copy with the same signing identity to
preserve its data.
