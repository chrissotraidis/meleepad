# MeleePad v0.1.0 Preview 6 — connection visibility

Build 28 adds **Slippi Connection Check** to Home Settings and the in-game
three-dot menu. It shows the current network route and the median response from
three requests to Slippi's website. This is a website reachability check, not a
measurement of matchmaking UDP or a future opponent's ping.

Once a peer connects, a larger in-game banner shows measured latency and warns
about sustained high latency, severe latency, rollback stalls, and missing
fresh ping samples. Rollback stalls can also involve local device performance.
The previous small Slippi readout remains available.

The maintainer installed the private build 28 in place on a physical iPad,
confirmed the game image and Slippi module were retained, read back matching
settings, and reached the native Slippi runtime. The new check and warning
banner have not yet been exercised in a live opponent match. Earlier builds
completed Unranked matches on iPad; this release does not claim a connection
stability or performance fix.

The downloadable IPA is **unsigned and module-free**. It is an app shell for
inspection, not a playable game. Importing an ISO or account cannot add the
missing native modules. Prepare your own compatible game image and modules,
then sign a complete private build using the [Slippi build guide](../SLIPPI-BUILD.md).
Do not install this public shell over an existing private playable build:
an app update replaces bundled modules. Keep the same bundle identifier and
signing team, and update the complete private build in place to retain data.
No game image, generated game module, Slippi account, saves, or signing material
is included in the public IPA.
