# Historical patch archive

These files document MeleePad's earlier integration and support legacy regression
fixtures. Normal bootstrap no longer applies them. The maintained source is the
pinned ModernGekko/RecompCore/DolRecomp/ENet fork graph in
[the dependency lock](../config/dependencies.lock.json).

Do not add production fixes to this archive. Commit dependency fixes to the
appropriate fork, retain upstream attribution, and update the selected pin with
validation. Private experiments are not promoted by adding them here.
